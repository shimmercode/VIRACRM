# 02 — ماتریس ردیابی الزامات (Traceability Matrix)

**Vira CRM** · Gate A · ۲ آذر ۱۴۰۵

منبع: `docs/requirements/requirements.catalog.yaml` (۸۴ الزام، ۱۵ بخش) و متن اصلی
`docs/requirements/source/Vira_CRM_Requirements_FA.txt`.

> **قاعدهٔ سخت که در این سند رعایت شده:** «صفحه وجود دارد» ≠ «الزام پیاده شده».
> الزام وقتی `IMPLEMENTED_VERIFIED` است که **کل گردش‌کار** با شاهد اجرایی کار کند.
> هر سلول «شاهد» یا مسیر فایل است یا دستور یا خروجی اجرا. جایی که شاهد ندارم،
> `NOT VERIFIED` نوشته‌ام.

## راهنمای وضعیت

| کد | معنا | معیار |
|----|------|-------|
| `IMPLEMENTED_VERIFIED` | کامل و با شاهد اجرایی تأیید شده | کل گردش‌کار + تست/اسکرین‌شات |
| `IMPLEMENTED_NOT_VERIFIED` | کد هست ولی شاهد کامل ندارم | فایل موجود، تست گردش‌کار نیست |
| `PARTIAL` | بخشی از گردش‌کار کار می‌کند | زیرمجموعه تأیید، بقیه نه |
| `NOT_IMPLEMENTED` | هیچ کد کاربردی نیست | جدول/Schema ممکن است باشد |
| `BLOCKED` | پیاده‌سازی ممکن نیست تا تصمیم/زیرساخت | علت ثبت شده |
| `AMBIGUOUS` | سند سکوت کرده یا متناقض است | نیازمند تصمیم شما |

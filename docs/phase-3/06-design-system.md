# 06 — Design System (Gate A)

**Vira CRM** · نسخهٔ ۱.۰ · ۲ آذر ۱۴۰۵

این سند **Design System موجود را مستند و تثبیت می‌کند**، نه اینکه از صفر بسازد.
Design System فعلی در `design-system/vira-crm/` و `resources/css/` است و ۲۱ سوییت
تست آن را می‌سنجد. آنچه اینجا اضافه می‌شود: **قواعد صریح برای کامپوننت‌هایی که هنوز
ساخته نشده‌اند**.

منبع حقیقت فنی: `resources/css/tokens.css` · `MASTER.md` · `component-guidelines.md`

---

## ۱. اصول طراحی (پنج اصل که هر تصمیم را می‌سنجد)

**اصل ۱ — تراکم اطلاعات بر تزئین.**
مدیر روزی ده بار به این صفحه نگاه می‌کند. هر پیکسل تزئینی که اطلاعات را عقب
می‌اندازد، هزینه دارد. داشبورد فعلی این اصل را رعایت می‌کند: ۵ KPI و کارتل در یک
نمای ۹۰۰px بدون اسکرول.

**اصل ۲ — برند از ساختار می‌آید، نه از تزئین.**
`#450073` و `#D2AB67` حفظ می‌شوند. طلایی **فقط** به‌عنوان لهجه (badge، جداکننده،
شمارنده) — هرگز رنگ متن اصلی یا پس‌زمینهٔ سطح.

**اصل ۳ — یک زبان بصری برای کل محصول.**
اگر کامپوننت جدیدی لازم شد، اول بررسی می‌شود آیا کامپوننت موجود کافی است.
دو کامپوننت برای یک مسئله = نقص Design System.

**اصل ۴ — RTL پیش‌فرض است، نه حالت اضافی.**
هر کامپوننت از ابتدا برای RTL ساخته می‌شود. `dir="ltr"` فقط برای مقادیر LTR
(شماره تلفن، ایمیل، URL، مبلغ با واحد لاتین) با `<bdi>` یا `dir="ltr"` + isolation.

**اصل ۵ — دسترس‌پذیری قابل تست است، نه ادعا.**
هر کامپوننت باید کیبورد-دسترس باشد، `:focus-visible` داشته باشد و نام قابل دسترس
داشته باشد. ۲۱ سوییت DS و `a11y.mjs` این را می‌سنجند.

## ۱۰. قواعد آیکن

- **یک مجموعه** (استروک ۱.۵px، ۲۴×۲۴، `currentColor`) — در `x-icon` رجیستری.
- اندازه‌ها: ۱۲ (chip)، ۱۶ (inline)، ۲۰ (دکمه)، ۲۴ (nav).
- آیکن تنها **بدون** برچسب ممنوع است، مگر `aria-label`.
- آیکن تزئینی: `aria-hidden="true"`.
- **ممنوع:** ایموجی به‌جای آیکن، آیکن‌های مخلوط از ست‌های مختلف.

## ۱۱. دسترس‌پذیری — تعهدهای قابل تست

| تعهد | تست |
|------|-----|
| کنتراست متن ≥۴.۵:۱ | `contrast.mjs` |
| حلقهٔ فوکوس دیده‌شدنی | `a11y.mjs` + `T-MX-focusring` |
| همهٔ کنترل‌ها با کیبورد | `a11y.mjs`, `regression-matrix.mjs` (`kbd` ≥۳) |
| نام قابل دسترس برای همهٔ کنترل‌ها | `a11y.mjs` |
| `role=status` برای اعلام تغییر | تست Spinner (فاز ۲-E) |
| `prefers-reduced-motion` | باید اضافه و تست شود (شکاف فعلی) |
| زبان `lang="fa"` و `dir="rtl"` | `regression-matrix.mjs` (۲۴ ترکیب) |

**شکاف صادقانه:** `prefers-reduced-motion` هنوز تست ندارد. باید در فاز ۳ اضافه شود.

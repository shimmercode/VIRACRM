# قواعد سند حسابداری

## چرخهٔ عمر

```
draft ──post──> posted ──reverse──> reversed
                    └──────────────> (mirror entry, posted)
```

در v1 سند همیشه مستقیماً `posted` ساخته می‌شود؛ حالت `draft` برای واردسازی و اصلاح دستی در آینده رزرو شده است.

## شماره‌گذاری

`JE-<سال مالی>-<چاررقمی>`، متوالی در هر دوره. عمداً یک شمارهٔ خودافزا سراسری نیست: حسابرس انتظار دارد اولین سند هر سال `0001` باشد و شکاف در شماره‌های یک سال شاهد حذف است.

## سند برگشتی

برگشت یک سند جدید می‌نویسد که بدهکار/بستانکار هر خط را جابه‌جا می‌کند. سند اصلی با `status = reversed` و `reversed_by_entry_id` باقی می‌ماند. هیچ‌چیز حذف نمی‌شود.

## منابع مجاز

| `source_type` | منبع |
|---|---|
| `invoice` | صدور فاکتور |
| `payment` | دریافت/پرداخت |
| `payroll` | دورهٔ حقوق |
| `expense` | هزینه |
| `opening` | سند افتتاحیه |
| `reversal` | سند برگشتی |

سند دستی بدون منبع در v1 ثبت نمی‌شود؛ فرم آزاد وجود ندارد.

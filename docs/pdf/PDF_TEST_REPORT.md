## باگ‌هایی که آزمون واقعی پیدا کرد

1. **`JalaliDate::fromCarbon()` نوع `CarbonImmutable` می‌خواست** و Eloquent برای
   cast تاریخ **`Carbon` قابل تغییر** برمی‌گرداند → TypeError روی دادهٔ معمولی مدل.
   امضا به هر دو نوع گسترش یافت. هیچ PDFای بدون این اصلاح ساخته نمی‌شد.
2. **`directionality => 'rtl'` تراز را راست نمی‌کند.** حروف درست به هم می‌چسبیدند و
   متن از چپ شروع می‌شد — روی کاغذ غلط است. `text-align: right` صریح شد.
3. **فیش حقوقی دو صفحه شد** و صفحهٔ دوم فقط پانویس داشت. استایل فشرده‌ی مخصوص
   همین سند اضافه شد.
4. **شمارهٔ قرارداد موروثی (`VIRA-D-001`) حفظ می‌شد** و سند نهایی با طرح
   شماره‌گذاری محصول هم‌خوان نبود. حالا همیشه شمارهٔ سال‌محور صادر می‌شود.
5. **`code` پروژه NULL بود** و نام فایل `CONFIDENTIAL-credentials-.pdf` می‌شد و
   ستون کد در سند خالی می‌ماند. هر دو به id و «ثبت نشده» fallback شدند.
6. **پانویس تاریخ میلادی با ارقام فارسی** چاپ می‌کرد — بدتر از تاریخ لاتین، چون
   ترجمه‌شده به نظر می‌رسد. جلالی شد.
7. **عنوان «قرارداد قرارداد …»** چون عنوان‌ها خودشان با «قرارداد» شروع می‌شوند.
8. **`{$e($employee?->displayName() ?? '—')}` داخل heredoc** خطای parse است؛ PHP
   آنجا فقط عبارت ساده را درج می‌کند. مقادیر قبل از heredoc در متغیر ریخته شدند.
9. **تست‌هایی که چیزی را اندازه نمی‌گرفتند.** `body.includes(contractNumber)` و
   جست‌وجوی رمز در بایت‌های PDF هرگز نمی‌توانند موفق شوند، چون mPDF متن را به
   صورت index گلیف می‌نویسد. این بررسی‌ها به لایهٔ HTML منتقل شدند، جایی که
   قابل سنجش‌اند.
10. **`myclabs/deep-copy` resolve نمی‌شد** — نام مخزن در GitHub `DeepCopy` است و
    `KNOWN_REPOS` آن را نداشت.

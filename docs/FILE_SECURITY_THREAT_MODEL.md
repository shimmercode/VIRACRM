# FILE_SECURITY_THREAT_MODEL — مدل تهدید Vira Drive

**نسخه:** 1.0 · **تاریخ:** ۲ آذر ۱۴۰۵ (2026-11-23) · **فاز:** F0 · **وضعیت:** Proposed — نیازمند تأیید کارفرما

> **اصل:** «بررسی شد» به‌معنای «امن است» نیست. هر کنترل **کد** و **تست** لازم دارد.
> **اصل دوم:** هر تهدیدی که Residual Risk دارد، صریح نوشته می‌شود — پنهان نمی‌شود.

## ۵. یافته‌های واقعی همین پروژه (نه تئوری)

| # | یافته | شاهد | اقدام |
|---|-------|------|-------|
| F-1 | `Storage::disk('local')->temporaryUrl()` روی `local` **قابل ابطال نیست** — امضا تا انقضا معتبر است | اجرا: امضا+tamper شد، ولی ساختار توکن فقط `expires+signature` دارد | برای دانلود حساس، از `file_access_tokens` استفاده شود، نه `temporaryUrl` |
| F-2 | امضای نامعتبر **به `/login` ریدایرکت می‌شود** (۳۰۲) | اجرا: `curl` با امضای tampered → ۳۰۲ به login | رفتار امن است (بدون داده) ولی UX گمراه‌کننده؛ در محیط پروژه، مسیر دانلود اختصاصی باید `403` بدهد نه ریدایرکت |
| F-3 | **بدنهٔ پاسخ ۰ بایت** در مسیر `storage.local` در محیط php-wasm | اجرا | یک اثر محیط تست است، **نه** باگ Laravel؛ در استقرار واقعی باید آزموده شود (`NOT TESTED`) |
| F-4 | Content-Type از **محتوا**، نه پسوند | اجرا: `photo.png` با HTML → `text/html` | DownloadController باید MIME **تأییدشده** را صریح ست کند |
| F-5 | CSP پیش‌فرض `sandbox` جلوی XSS را می‌گیرد ولی `inline` است | اجرا | برای `.html`/`.svg` استفادهٔ مستقیم **ممنوع** شود |
| F-6 | `League\Flysystem\PathTraversalDetected` در برابر `..` مقاوم است | اجرا: ۳ الگوی حمله رد شد | لایهٔ سوم؛ لایهٔ اول و دوم در طراحی ما |

> **این‌ها ادعای امنیتی نیستند**؛ یافتهٔ مهندسی در محیط تست‌اند.

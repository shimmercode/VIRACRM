## ۲. باگ‌های واقعی که تست‌ها پیدا کردند

این‌ها دقیقاً همان چیزی هستند که «طراحی» هرگز نشانشان نمی‌دهد:

| # | باگ | اثر اگر پیدا نمی‌شد |
|---|---|---|
| ۱ | `$x = ($a<0) xor ($b<0)` — تقدم عملگر در PHP | **همه محاسبات درصدی = ۰ ریال**؛ فیش حقوقی صفر |
| ۲ | `sodium` روی این PHP نیست | رمزنگاری در اولین استفاده Fatal می‌داد |
| ۳ | `$negative = ... xor ...` بدون پرانتز دور کل عبارت | همان باگ ۱ بار دوم |
| ۴ | `Money::parse('1,2,3')` → ۱۲۳ | غلط تایپی = مبلغ فاکتور اشتباه |
| ۵ | `SODIUM_*` در class constant | Fatal در لحظه لود کلاس |
| ۶ | delimiter `#` داخل `#[/?#].*$#` | استخراج دامنه بی‌صدا شکست می‌خورد |
| ۷ | Closure `$term` ثبت نشده | جستجو با `Undefined variable` می‌شکست |
| ۸ | `Capsule::bootEloquent()` بدون dispatcher | **همه hookهای مدل بی‌صدا اجرا نمی‌شدند** |
| ۹ | `Model::clearBootedModels()` لازم | مدل‌ها به dispatcher قدیمی وصل می‌ماندند |
| ۱۰ | تست‌ها DB مشترک | تست‌ها order-dependent و گمراه‌کننده |

> مورد ۱ و ۲ از جنس خطاهایی هستند که به **فیش حقوقی امضاشده** یا **Fatal روی
> هاست مشتری** می‌رسیدند. این تنها دلیل موجه برای ساختن harness واقعی است.

## ۴. صداقت گزارش: چه چیزی هنوز **اثبات نشده**

| ادعا | وضعیت واقعی |
|---|---|
| «روی MySQL کار می‌کند» | ❌ **تست نشد** — MySQL server در این محیط نیست |
| «روی هاست مشترک نصب می‌شود» | ❌ **تست نشد** — دسترسی به هاست نداریم |
| «Composer نصب می‌کند» | ⚠️ `composer.lock` تولید نشده — باید روی هاست ساخته شود |
| «PHPUnit اجرا شد» | ❌ اجرا نشد — به‌جای آن shim؛ همان کد تست روی PHPUnit قابل اجراست |
| «۱۲۹ تست باقی‌مانده شکست می‌خورند» | ❌ تست نشده‌اند (`NOT_RUN`)، نه شکست‌خورده |

هیچ‌کدام از این‌ها در گزارش به‌عنوان PASS ثبت نشده‌اند.

اندازه‌گیری شد، نه حدس.

## ۷. قواعد سخت

1. **هیچ رنگ برندی تغییر نمی‌کند**
2. **هیچ متنی زیر ۱۲px نیست**
3. **وضعیت هرگز فقط با رنگ بیان نمی‌شود**
4. **اقدام حیاتی هرگز فقط با hover**
5. **هیچ توکن تعریف‌نشده** (`tokens` suite)
6. **هیچ کلاس بی‌استایل** (`unstyled` suite)
7. **همهٔ جفت‌ها ≥ ۴.۵:۱** (`contrast` suite)

**این هفت قاعده مکانیکی تست می‌شوند، نه توصیه.**

# 15 — نقشهٔ راه اجرا (Gate A → Gate B)

**Vira CRM** · Gate A · ۲ آذر ۱۴۰۵

---

## ۱. اصل حاکم

دستور §21 شش میلی‌استون تعریف کرد. آن ساختار **درست است** و حفظ می‌شود، ولی
ترتیب داخل آن را بر اساس **وابستگی واقعی کد** بازچینی کردم، چون:

- PDF پیش‌نیاز قرارداد نهایی **و** فیش حقوقی است.
- Credentials پیش‌نیاز نهایی‌سازی پروژهٔ سئو است.
- Reminder Engine پیش‌نیاز داشبورد واقعی است.

**هیچ میلی‌استونی «کامل» اعلام نمی‌شود مگر ۱۰ معیار بند ۸ سند تست را داشته باشد.**

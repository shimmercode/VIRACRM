# گزارش‌های مالی

همه چیز از `journal_lines` محاسبه می‌شود — نه از جدول فاکتور و پرداخت. یک جدول فاکتور می‌تواند بگوید چه چیزی صورت‌حساب شد؛ فقط دفتر می‌تواند بگوید کسب‌وکار چه درآمدی **شناسایی** کرد، چون اعتبارها، برگشت‌ها و مرز دوره‌ها را هم می‌داند.

| گزارش | متد | ماهیت |
|---|---|---|
| تراز آزمایشی | `trialBalance($periodId)` | جمع بدهکار/بستانکار هر حساب + بررسی تراز |
| سود و زیان | `profitAndLoss($periodId)` | درآمد − هزینه؛ `net = null` اگر داده نباشد |
| ترازنامه | `balanceSheet($asOf)` | دارایی = بدهی + حقوق مالکانه (+ سود دورهٔ جاری) |
| درآمد به تفکیک | `revenueBy($dimension)` | مشتری / پروژه / خدمت / دپارتمان |

## قواعد نمایش

1. هر عدد به **ریال** و با ارقام فارسی.
2. مبلغ صفر ساخته نمی‌شود؛ `has_data` اول بررسی می‌شود.
3. عدم تراز، هشدار قرمز روی صفحه است — نه استثنا که بقیهٔ گزارش را پنهان کند.
4. ستون‌های پول با `tabular-nums` و `dir=ltr` تا ستون روی رقم هم‌تراز شود.

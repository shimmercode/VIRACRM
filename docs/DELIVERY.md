## ۲. چطور ساخته شد (قابل بازتولید)

```bash
# منبع: فقط فایل‌های نسخه‌بندی‌شده، از خود Git — نه از پوشهٔ کاری
git archive HEAD | tar -x -C stage/viracrm

# دارایی ساخته‌شده اجباری است: public/build در .gitignore است،
# پس ZIPِ خالی از Git صفحهٔ بی‌استایل تحویل می‌دهد.
cp -r public/build stage/viracrm/public/build

# فهرست هش، سپس zip
cd stage/viracrm && find . -type f -exec sha256sum {} \; | sort -k2 > MANIFEST.sha256
zip -qr -9 viracrm-source.zip viracrm
```

> **چرا `git archive` و نه `zip -r` از پوشهٔ کاری:** پوشهٔ کاری شامل
> `.env`، `database/*.sqlite`، `storage/logs/` و `.arena/` است. `git archive`
> فقط آنچه را می‌آورد که در تاریخچه است، پس یک فایل نادیده‌گرفته‌شده
> نمی‌تواند سهواً وارد بسته شود.

## ۵. پنج باگی که این چرخه پیدا کرد

هر پنج مورد در حین «اتصال» پیدا شدند، نه در حین «نوشتن». این دقیقاً همان
دلیل وجود تست یکپارچه است.

| # | باگ | چطور پیدا شد | اثر اگر پیدا نمی‌شد |
|---|-----|--------------|---------------------|
| ۱ | `CredentialVault` در constructor استثنا می‌داد | اجرای واقعی صفحه با کلیدِ نبود | **۵۰۰ روی همهٔ** صفحات دسترسی، حتی فهرست فقط‌خواندنی |
| ۲ | `Flow.render()` مقدار `env` را دور می‌ریخت | تست flow روی دیتابیس اشتباه اجرا می‌شد | تست روی **دیتابیس مشترک** می‌نوشت — همان شکست ایزولاسیونی که harness برای منعش ساخته شده |
| ۳ | `is-invalid` کلاس تعریف‌نشده بود | `unstyled.mjs` | خطای اعتبارسنجی **هیچ نشانهٔ بصری** نداشت |
| ۴ | پروکسی `X-CSRF-TOKEN` را رد می‌کرد | کلیک واقعی روی دکمهٔ reveal در مرورگر | هر نوشتن AJAX در Preview **۴۱۹** می‌داد؛ test های PHP با `_token` در body سبز بودند |
| ۵ | فهرست دسترسی‌ها `v-table-wrap` داشت به‌جای `.v-tablewrap` | اسکرین‌شات ۳۹۰px | نمای موبایل، جدول دسکتاپ فشرده بود و ستون عملیات **بریده** می‌شد |

# FILE_STORAGE_CAPACITY_PLAN — ظرفیت، کارایی و هزینه

**نسخه:** 1.0 · **تاریخ:** ۲ آذر ۱۴۰۵ (2026-11-23) · **فاز:** F0 · **وضعیت:** Proposed — **هیچ عددی تضمین Production نیست**

> **هشدار روش‌شناختی:** همهٔ اعداد این سند یا (الف) **اندازه‌گیری‌شده در سندباکس روی php-wasm** هستند، یا (ب) **برآورد مهندسی با فرض صریح**. هیچ‌کدام روی cPanel یا VPS واقعی اندازه‌گیری نشده.
> طبق دستور §19: «Benchmark محیط توسعه را به‌عنوان Performance تضمین‌شده Production معرفی نکن.»
> قیمت‌ها **استعلام لازم** دارند؛ عدد ریالی/دلاری قطعی در این سند نیست.

### ۲.۲. محاسبهٔ سال اول

```
روزانه:
  فایل معمولی  = 15 × 8 × 0.95 × 1.5 MB      ≈ 171 MB
  فایل بزرگ    = 15 × 8 × 0.05 × 180 MB      ≈ 1,080 MB
  خام روزانه                                  ≈ 1,251 MB/روز
  با نسخه‌ها (×2.2)                            ≈ 2,752 MB/روز
  منهای حذف (۳٪)                               ≈ 2,670 MB/روز

سال اول (۲۵۰ روز کاری):
  ≈ 651 GB
```

**نتیجه: نیاز سال اول ≈ ۶۵۰ گیگابایت** با فرض‌های بالا.

## ۵. منابع VPS — برآورد

### ۵.۱. تفکیک حداقل/پیشنهادی

| منبع | حداقل | پیشنهادی | سنگین (۵۰ کاربر) | مبنای محاسبه |
|------|-------|----------|-------------------|--------------|
| vCPU | ۲ | ۴ | ۸ | ۴ PHP-FPM worker × ۱ core هر ۲ |
| RAM | ۲ GB | ۸ GB | ۱۶ GB | 2GB OS + ۲۵۶MB×workers + cache |
| Disk (OS+temp) | ۲۰ GB | ۴۰ GB | ۸۰ GB | multipart temp برای ۴GB |
| Bandwidth | ۱ TB/ماه | ۴ TB/ماه | ۱۰ TB/ماه | ۵۰GB/روز × ۲۰ روز |
| IOPS | ۳۰۰ | ۱٬۰۰۰ | ۳٬۰۰۰ | فقط برای temp؛ bytes در S3 |
| Backup space | ۲۰٪ فعال | ۵۰٪ فعال | ۱۰۰٪ | برای بازیابی |

### ۵.۲. چرا RAM پیشنهادی ۸GB؟

```
- OS Ubuntu minimal         ~ 400 MB
- nginx                     ~ 50 MB
- PHP-FPM (8 workers × 64MB) ~ 512 MB
- APCu cache مجوز           ~ 128 MB
- MySQL/MariaDB محلی (اگر)  ~ 1 GB
- Headroom برای multipart   ~ 4 GB   ← برای فایل ۴GB باید temp روی دیسک باشد، نه RAM
```

**نکتهٔ مهم:** `proxy_request_buffering off` در nginx باعث می‌شود بدنه به دیسک **یا** استریم رود؛ اگر روی RAM باشد، فایل ۴GB سیستم را می‌کشد. **این باید تنظیم شود: `client_body_temp_path` روی دیسک.**

## ۷. هزینه — چارچوب، نه قیمت

> **قیمت واقعی باید استعلام شود.** زیر فقط **ساختار هزینه** است تا کارفرما بتواند مقایسه کند.

| قلم | ماهیت | متغیر اصلی | نیازمند استعلام |
|-----|-------|------------|:---------------:|
| VPS WebDAV | ماهانه | vCPU/RAM/BW | ✅ |
| Object Storage | ماهانه + ترافیک | حجم ذخیره + egress | ✅ |
| Backup Storage | ماهانه | حجم + نگهداری | ✅ |
| دامنه + TLS | سالانه | — | ❌ (Let's Encrypt رایگان) |
| نیروی نگهداری | ماهانه | ساعت/ماه | ✅ (داخلی) |
| پشتیبانی | توافقی | SLA | ✅ |

**روش تصمیم:** سه ارائه‌دهندهٔ ایرانی + یک ارائه‌دهندهٔ خارجی (اگر قانونی مجاز است) استعلام شود؛ مقایسه بر **هزینهٔ کل مالکیت سه‌ساله**، نه قیمت ماه اول.

## ۸. سیاست رشد و مقیاس‌پذیری

| آستانه | اقدام |
|--------|-------|
| >۷۰٪ ظرفیت Storage | هشدار + برنامهٔ افزودن Backend |
| >۸۵٪ | هشدار قرمز + بازبینی سهمیه‌ها |
| p95 فهرست > ۲s | بررسی ایندکس/کش |

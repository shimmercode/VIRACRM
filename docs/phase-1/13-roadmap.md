# VIRA CRM — برنامه اجرایی فازهای توسعه (فاز ۱)

> ترتیب توسعه بر اساس **وابستگی واقعی** و **ریسک** است، نه فقط ترتیب بریف.
> هر فاز فقط با «خروجی قابل اجرا + شواهد» پایان می‌یابد.

## گیت فعلی

```text
فاز ۰ (بررسی env) ✅ انجام شد (هاست: BLOCKED)
فاز ۱ (تحلیل و طراحی) ✅ خروجی آماده — منتظر تأیید کارفرما
        ⛔ توقف: توسعه اصلی شروع نمی‌شود تا تأیید کتبی/صریح
```

## فاز ۶ — استقرار

1. اجرای اسکریپت سازگاری هاست (Q-01..Q-04)
2. ساخت DB و کاربر محدود
3. تنظیم Document Root و SSL
4. آپلود بسته + `.env` + `migrate --force` + seed تنظیمات
5. Cron + تست Scheduler
6. Backup اولیه + تست Restore
7. Installer/قفل نصب

## فاز ۷ — تحویل

ZIP قابل انتقال + مستندات + نمونه PDF/Excel/Backup + RTM + گزارش تست/امنیت + Known Issues.

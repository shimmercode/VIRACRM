## ۱۰. پروژهٔ سئو — **جدید (مهم‌ترین صفحهٔ عملیاتی)**

```
[کد] [عنوان] [وضعیت]              [نهایی‌سازی] [PDF عمومی]
──────────────────────────────────────────────────────────
اطلاعات پایه: مشتری · دامنه · پکیج · مبلغ · تاریخ · مسئول
──────────────────────────────────────────────────────────
KPI: کلمات کلیدی ۲۴ · فاکتور بعدی ۱۴۰۵/۰۹/۱۰ · گزارش بعدی ...
──────────────────────────────────────────────────────────
[تب] کلمات کلیدی | فاکتورها | گزارش‌ها | دسترسی‌ها | اسناد
──────────────────────────────────────────────────────────
کلمات کلیدی: جدول (کلمه · رتبه فعلی · رتبه هدف · وضعیت)
فاکتورها:    جدول رویداد (موعد · مبلغ · وضعیت · انجام)
گزارش‌ها:     جدول رویداد (دوره · موعد · فایل · وضعیت)
دسترسی‌ها:   جدول ماسک‌شده + دکمهٔ نمایش
اسناد:        آپلود + فهرست
```

**Tabs اینجا مجاز است** چون ۵ گروه محتوای متفاوت با حجم زیاد است — تنها جایی که
دستور §8 بند ۲۳ اجازه داده ("فقط با توجیه گردش‌کار واقعی").

**قاعدهٔ نهایی‌سازی:** اگر دسترسی اجباری incomplete → دکمه غیرفعال + متن دلیل
(نه مخفی). کلیک → پیام صریح.

## ۱۱. پروژهٔ طراحی سایت — **جدید**

فیلدها: دامنه · نوع سایت · شرح کار · مبلغ · تاریخ · مسئول · اطلاعات دسترسی لازم.

**قاعده:** فیلدهای سئو (کلمات کلیدی، پکیج سئو) **نمایش داده نمی‌شوند**. فرم

## ۱۲. دسترسی‌های پروژه — **جدید (حساس‌ترین صفحه)**

```
[عنوان پروژه] → دسترسی‌ها
─────────────────────────────────────────────────────
[+ افزودن دسترسی]
─────────────────────────────────────────────────────
نوع            URL              username    رمز      آخرین تغییر
WordPress      example.com/wp   admin       ••••••   ۱۴۰۵/۰۸/۱۲
Hosting        cpanel.example   virauser    ••••••   ۱۴۰۵/۰۷/۰۳
GSC            search.google... —           ••••••   ۱۴۰۵/۰۶/۲۰
─────────────────────────────────────────────────────
[PDF محرمانه]  ⚠ این فایل حاوی رمز است
[دریافت رمز از سرور پس از تأیید مجوز + ثبت در رویدادها]
```

**قواعد سخت:**

1. رمز **هرگز** در HTML فهرست نیست — فقط `••••••`.
2. «نمایش» درخواست `POST` می‌زند، پاسخ `no-store`.
3. خودکار مخفی پس از ۳۰ ثانیه.
4. نوار هشدار کهنگی: «این رمز ۹۰ روز عوض نشده».
5. نشان دسترسی اجباری: `WordPress ✔ اجباری` / `GSC — اختیاری`.

# CRM_REVIEW_DESIGN — سیستم طراحی، جزء‌به‌جزء

> این سند می‌گوید هر صفحه از چه اجزایی ساخته شده و **از کدام منبع**.
> هیچ صفحه‌ای مستقل از اپلیکیشن نوشته نشده است.

## ۱. اصل بنیادین: همان اپلیکیشن، نه یک نمونهٔ جدا

محیط بازبینی یک پروژهٔ دیگر نیست. هر صفحه از مسیر واقعی Laravel رد می‌شود:

```
HTTP → routes/review.php → ReviewController → resources/views/... → layouts.app
```

| لایه | منبع | مشترک با محصول؟ |
|---|---|---|
| Layout | `resources/views/layouts/app.blade.php` | ✔ همان فایل |
| Sidebar | `components/nav` + `config/navigation.php` | ✔ همان |
| Topbar | `components/topbar` | ✔ همان |
| دکمه/فیلد/جدول | `public/build/css/app.css` | ✔ همان |
| فونت | Vazirmatn محلی در `public/build/fonts` | ✔ همان |
| لوگو | `Group 2016.png` (دارایی رسمی VIRA) | ✔ همان |
| پالت | `#450073` / `#D2AB67` / `#211B2B` / `#F6F5F8` / `#FFFFFF` | ✔ همان |

تنها استثناء: `public/build/css/review.css` (۲۸۸ خط). این فایل **فقط**
اجزایی را اضافه می‌کند که محصول ندارد و فقط بازبینی به آن‌ها نیاز دارد.

## ۲. واژگان وضعیت — چهار مقدار، نه بیشتر

| برچسب | معنا | رنگ |
|---|---|---|
| `Functional` | مسیر واقعی + کوئری واقعی + تعامل واقعی | سبز |
| `Partial` | داده واقعی هست، منطق کامل نیست | کهربایی |
| `UI Preview` | فقط طراحی؛ هیچ بک‌اندی ندارد | بنفش |
| `Not Implemented` | صفحه وجود ندارد | خاکستری |

کامپوننت: `resources/views/components/review-status.blade.php`

`review-integrity.mjs` بررسی می‌کند که **هیچ** ردیفی بیرون از این چهار
مقدار نباشد. اگر کسی «Designed» یا «In Progress» اضافه کند، تست می‌شکند.

## ۳. اجزای صفحهٔ فهرست (`/review`)

| جزء | کلاس/path | نقش |
|---|---|---|
| Hero | `.v-page-head` | عنوان + توضیح که این محیط چیست |
| چهار کاشی شمارش | `.v-review-stat` | تعداد هر وضعیت — از کاتالوگ محاسبه می‌شود |
| بنر جداسازی | `.v-alert--info` | «هیچ اتصالی به تولید وجود ندارد» |
| جدول گروه‌بندی‌شده | `.v-table` | ۲۷ ردیف، گروه‌بندی بر اساس ماژول |
| توضیح ردیف | `.v-review-note` | زیر هر ردیف، نه داخل سلول (بعد از نقص سرریز) |

## ۴. اجزای پیش‌نمایش‌ها

### ۴.۱ Vira Drive — سه‌پنلی

`.v-review-split` — گرید سه‌ستونه: پوشه‌ها | فهرست فایل | جزئیات
- ≤۱۱۸۰px → دو ستون
- ≤۸۲۰px → یک ستون
- جدول فایلها `table-layout: fixed` با ۴ ستون (بعد از نقص کلیپ‌شدن Badge)

### ۴.۲ بنر پیش‌نمایش

`review/partials/preview-banner.blade.php` — سه پارامتر اجباری:
`what` (چه صفحه‌ای)، `why` (چرا بک‌اند ندارد)، `clickable` (کدام دکمه کار نمی‌کند).

### ۴.۳ بنر منشأ داده

`.v-review-provenance` — سه حالت متمایز:

| حالت | رنگ | چه وقت |
|---|---|---|
| `--demo` | بنفش | صفحه به جدول واقعی وصل است و ردیف دارد |
| `--empty` | کهربایی | وصل است ولی صفر ردیف — «خالی بودن اثبات نیست» |
| `--design` | خاکستری | هیچ کوئری‌ای اجرا نشده |

این بنر تفاوت «صفحهٔ طراحی» و «صفحهٔ داده‌دار» را روی خود صفحه می‌گذارد،
نه در سند.

## ۵. اجزای مشترک محصول که استفاده شده

| جزء | استفاده در |
|---|---|
| `.v-card`, `.v-card__head`, `.v-card__body` | همهٔ صفحات |
| `.v-table`, `.v-table-wrap`, `.v-table--fixed` | فهرست‌ها |
| `.v-badge--{success,warning,danger,info,neutral}` | وضعیت‌ها |
| `.v-empty` | حالت خالی |
| `.v-alert--{info,danger}` | هشدارها |
| `.v-dl` + `__term`/`__value` | صفحهٔ جزئیات فایل |
| `<x-icon>` | آیکون‌ها — بدون کتابخانهٔ خارجی |

## ۶. حالت‌های اجباری

| حالت | کجا | وضعیت |
|---|---|---|
| Empty | تیم پروژه با ۰ تخصیص | ✔ پیاده‌شده و تست‌شده |
| Loading | فرم‌های CRUD واقعی | ✔ در محصول؛ پیش‌نمایش‌ها عملیات ندارند |
| Error | بنر `dataError` در کنترلر | ✔ مسیر خطا وجود دارد |
| Permission-Denied | ۴۰۳ واقعی با `review.viewer` | ✔ تست‌شده |
| Mobile | ۳۹۰/۴۳۰ | ✔ اندازه‌گیری واقعی |

## ۷. RTL و تایپوگرافی

- `dir="rtl"` و `lang="fa"` روی `<html>`
- اعداد فارسی از طریق `Labels`/`Number` — نه تبدیل دستی
- تاریخ شمسی از `morilog/jalali` — همان مسیر محصول
- هیچ فونت خارجی از CDN بارگذاری نمی‌شود (CSP: `font-src 'self'`)

## ۸. دسترس‌پذیری

| مورد | وضعیت |
|---|---|
| کنتراست متن | بررسی‌شده با `tools/checks/contrast.mjs` (در محصول) |
| ناوبری با کیبورد | سایدبار و فرم‌ها focus-visible دارند |
| `aria-label` روی آیکون‌های تنها | ✔ |
| حالت کاهش انیمیشن | احترام به `prefers-reduced-motion` در `app.css` |
| تست با Screen Reader | **انجام نشده** — در محدودیت‌ها ثبت شده |

## ۹. چیزی که این طراحی **نیست**

- یک قالب آمادهٔ Bootstrap نیست: هیچ کلاس `col-md-*` یا `btn btn-primary` وجود ندارد.
- یک نمونهٔ HTML مستقل نیست: هیچ صفحه‌ای بدون Layout واقعی رندر نمی‌شود.
- مجموعه‌ای از اسکرین‌شات نیست: هر صفحه URL واقعی دارد و قابل ناوبری است.
- یک طراحی جدا از محصول نیست: همان CSS، همان فونت، همان اجزا.

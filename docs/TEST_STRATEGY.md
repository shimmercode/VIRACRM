## ۴. قفل اجرا (§14.2 — پیاده‌شده)

### مشکل واقعی

سوییت‌ها پوشهٔ `.arena/flows/<suite>/` را مشترک دارند و `browser-flow.mjs` با
`rmSync` شروع می‌کند. **دو اجرای هم‌زمان، دیتابیس یکدیگر را پاک می‌کنند.**

این تئوری نبود — در فاز ۲-E دقیقاً همین خطا دیده شد:
```
Database file at path [.arena/flows/crud/database.sqlite] does not exist
```
که شبیه باگ محصول بود، اما رقابت اجرا بود.

### راه‌حل

`lib/run-lock.mjs` — قفل اتمی با `fs.openSync(..., 'wx')` (`O_CREAT|O_EXCL`).

**چرا `flock` نه:** هاست cPanel قابل اتکا نیست، و Node API قفل advisory قابل
حمل ندارد. `O_EXCL` روی همهٔ فایل‌سیستم‌های هدف کار می‌کند.

| Exit code | معنا |
|-----------|------|
| ۰ | همه سبز |
| ۱ | شکست |
| ۲ | ناتمام (`--fast`) |
| **۳** | **قفل در دست اجرای دیگر** |

**۳ عمداً جدا از ۱ است:** CI باید «کد خراب است» را از «کسی دیگر در حال اجراست»
تشخیص دهد.

### بازیابی — تست‌شده نه فرض‌شده

| سناریو | رفتار |
|--------|-------|
| pid مرده، همان هاست | قفل تصرف می‌شود |
| فایل خراب | stale تلقی می‌شود |
| قفل > ۳ ساعت | تصرف می‌شود |
| **SIGKILL** | **تست واقعی شد — بازیابی می‌شود** |
| قفل مال دیگری | `release()` آن را حذف نمی‌کند |

## ۵. تکرارپذیری (§14.5)

`--repeat 2` **پنج بُعد** را مقایسه می‌کند:

1. فهرست سوییت‌ها (سوییت ناپدیدشده = شکست)
2. تعداد اَسِرشِن هر سوییت
3. تعداد پاس هر سوییت
4. مجموعهٔ سوییت‌های شکست‌خورده
5. مجموعهٔ سوییت‌های skip شده

خروجی در `.arena/repeat-<stamp>.json` برای بازرسی بعدی.

**قبل از این تغییر:** فقط مجموع کل مقایسه می‌شد — سوییتی که ناپدید شود،
تعداد یکسان می‌داد و تفاوت دیده نمی‌شد.

## ۶. جداسازی دیتابیس

اندازه‌گیری **حول هر pass** انجام می‌شود، نه یک‌بار دور کل فرمان. تفاوت:
اگر pass ۱ نشت کند و pass ۲ آن را بپوشاند، روش قبلی نشت را گزارش نمی‌کرد.

پاسخ هر pass: `isolation: shared database untouched` یا `LEAKED`.

## ۸. معیار «تمام‌شدن» یک ماژول (۱۰ شرط)

1. Route + مجوز
2. Controller + Form Request
3. Model + روابط
4. صفحهٔ فهرست + صفحهٔ جزئیات
5. جریان CRUD کامل در مرورگر
6. حالت خالی + حالت خطا
7. تاریخ شمسی + مبلغ صحیح
8. `dir=rtl` در ۷ عرض، بدون سرریز
9. جدول → کارت در موبایل
10. اَسِرشِن در سوییت ثبت‌شده

**بدون هر ۱۰ مورد، ماژول تمام نشده** — حتی اگر صفحه باز شود.

# CRM_REVIEW_ACCESS — دسترسی به محیط بازبینی

> این سند فقط دربارهٔ «چطور وارد شوم» است. ادعایی دربارهٔ آمادگی محصول نمی‌کند.

## ۱. آدرس

| محیط | آدرس |
|---|---|
| پیش‌نمایش زنده | `https://4173-{sandboxId}.e2b.app/review` |
| صفحهٔ فهرست | `/review` — همهٔ ۲۷ صفحه با وضعیت هرکدام |
| سلامت محیط | `/review/health` — فقط تعداد ردیف، بدون داده |

سرور روی `0.0.0.0:4173` گوش می‌دهد و از طریق پراکسی پیش‌نمایش در دسترس است.
این یک محیط **بازبینی** است، نه Staging تولیدی و نه Production.

## ۲. حساب‌های نمایشی

رمز هر چهار حساب: `ReviewDemo!2026`

| نام کاربری | نقش واقعی | Superadmin | چه چیزی می‌بیند |
|---|---|---|---|
| `review.admin` | manager | بله | همهٔ صفحات |
| `review.manager` | manager | خیر | مشتریان/قراردادها/پروژه‌ها؛ **بدون** صفحهٔ ساختار سازمانی |
| `review.employee` | account_manager | خیر | ساخت مشتری؛ بدون ساختار سازمانی |
| `review.viewer` | viewer | خیر | فقط مشاهده؛ همهٔ مسیرهای ساخت → ۴۰۳ |

رمز از `.env` خوانده نمی‌شود؛ ثابتِ سیدر است و **فقط در دیتابیس بازبینی** معنا دارد.
هیچ رمز واقعی یا رمز Production در این محیط نیست.

> **هشدار:** این رمزها در مخزن عمومی ناموجودند و نباید در سند عمومی منتشر شوند.
> خودِ الگوی رمز در `database/seeders/ReviewDemoSeeder.php` است و بدیهی است.

## ۳. اجرای محلی

```bash
node tools/review-env.mjs init      # ساخت کپی دیتابیس از اسکیمای پایه
node tools/review-env.mjs seed      # پر کردن با داده ساختگی
node tools/review-env.mjs serve     # سرور روی پورت ۴۱۷۳
node tools/review-env.mjs status    # تعداد ردیف‌ها
node tools/review-env.mjs reset     # پاک کردن دقیقاً همان ردیف‌هایی که سیدر ساخت
```

`init` فایل پایه را فقط **می‌خواند**؛ خروجی همیشه
`database/review/crm-review.sqlite` است و این مسیر در `.gitignore` قرار دارد.

## ۴. چه چیزی در این محیط **نیست**

- هیچ اتصال به Production، هیچ داده واقعی مشتری، هیچ ایمیل/SMS/پرداخت واقعی.
- هیچ Migration جدید — محیط بازبینی روی اسکیمای موجود اجرا می‌شود.
- هیچ راه‌اندازی WebDAV — `Vira Drive` در وضعیت **UI Preview** است.
- هیچ تصمیم مشتری بسته نشده است.

## ۵. اگر صفحه باز نشد

| نشانه | معنا | کار |
|---|---|---|
| ۴۰۴ روی `/review` | `VIRA_REVIEW_ENABLED=false` یا محیط مجاز نیست | `.env` را بررسی کنید |
| ۴۰۳ روی یک صفحه | نقش شما آن مجوز را ندارد — رفتار درست است | با `review.admin` وارد شوید |
| جدول خالی | سیدر اجرا نشده | `node tools/review-env.mjs seed` |
| ۵۰۰ | خطای واقعی | لاگ سرور؛ صفحه هرگز خطا را پنهان نمی‌کند |
